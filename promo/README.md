## Як змінити й перерендерити

- `shturman-promo.html` — уся анімація; кожен кадр — чиста функція часу `seek(t)`.
  Відкрийте у браузері для перегляду в реальному часі, `?t=12.5` — заморозити кадр.
- `music.py` — синтезований саундтрек (лише numpy); UI-акценти прив'язані до тих самих
  таймінгів, що й анімація — при зміні таймінгів сцени оновіть обидва файли.
- `render.mjs` — Playwright → JPEG-кадри → ffmpeg.

```bash
python3 promo/music.py                       # promo/out/music.wav
node promo/render.mjs                        # promo/out/shturman-promo.mp4 (~2 хв)
node promo/render.mjs --stills 3,12.5,42     # окремі кадри для перевірки
```
