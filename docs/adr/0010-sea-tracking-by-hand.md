# Sea containers are tracked by hand

Parcels and express go through 17TRACK and Нова Пошта. Sea containers and B/Ls are updated by logists (`TRACKING_SEA_MODE=manual`), and the live map estimates the missing dates from route length. Free carrier APIs cover only own bookings, and paid aggregators (about $2 per container plus an API fee) were not worth it at 30–50 shipments a month (decided 2026-10-09).
