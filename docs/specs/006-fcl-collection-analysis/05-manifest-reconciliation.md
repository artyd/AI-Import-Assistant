# 05 — Маніфест ↔ документи

Status: resolved
Blocked by: 04

## Що зробити

- `reconciliation/manifest.ts` (чисто): рядки маніфесту (парсер `analysis/sheets/parse.ts`) ↔
  позиції інвойсів усіх партій (`line_items`, інакше `product_name` + ваги). Нечіткий збіг
  назв (токени, CAS, без регістру/пунктуації). Звірка кг (1%) і ціни за одиницю (0.5%).
  Рядок без інвойсу / товар поза маніфестом → 🟡. Вихід: таблиця відповідностей +
  розбіжності для FCL.
- Джерело маніфесту: останній xlsx/csv у `01_Маніфест` (або витяг `transport_doc_kind='manifest'`).
- Якщо маніфесту немає: `buildManifestFromInvoices(...)` → CSV-текст (Назва, Кількість кг, Ціна,
  Код) → той самий аналіз; `run_consolidated_analysis` бере його як джерело з позначкою
  «зібрано з інвойсів».
- Результат звірки входить у вердикти FCL (04) і в XLSX (08).

## Приймання

Юніт-тести: точний збіг, розбіжність кг, рядок без інвойсу, товар поза маніфестом,
автозбирання маніфесту.
