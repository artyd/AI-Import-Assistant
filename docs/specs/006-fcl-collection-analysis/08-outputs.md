# 08 — Дії: інструкція, звіт, ZIP, XLSX

Status: ready-for-agent
Blocked by: 06

## Що зробити

- Інструкція по партіях: `supplier_instructions.lot_id`; prefill з документів і контексту партії;
  маршрути інструкції приймають `?lotId=`; отримувач за замовчуванням — отримувач партії або FCL.
- Звіт керівництву FCL: факти FCL — контейнер, маршрут, платежі з аналізу, статус, ризики + рядок
  на кожну партію; той самий PDF-шаблон.
- ZIP: `FCL/<тип>/файл` + `<Партія — X>/<тип документа>/файл`.
- XLSX аналізу: + аркуші «Звірка маніфесту», «Розбіжності», «Ризики по партіях».
