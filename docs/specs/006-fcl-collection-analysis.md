# ТЗ: Збірник (FCL) — глибокий аналіз як у Постачання

Status: ready-for-agent

Сьогодні Збірник лише зберігає файли й рахує маніфест (`run_consolidated_analysis`).
Документи (PDF, сертифікати, коносаменти) ніхто не читає. Немає комплектності,
розбіжностей, ризиків, сторін, контексту, верифікації, інструкції, звіту. Реальний
збірний контейнер («Сборник 18 Китай», 196 файлів, 5 постачальників) тому
перевіряли як звичайне Постачання.

Рішення погоджено з замовником 2026-10-22 (аудит з варіантами відповідей). Ця
специфікація замінює рядок GLOSSARY «a collection is deliberately never reconciled».

## Погоджені рішення

| Питання | Рішення |
|---|---|
| Що таке Збірник | **FCL, який ми веземо собі**: одна велика поставка (контейнер, транспорт, контекст, підсумки) **+ партії всередині** |
| Технічна основа | **Збірник = вид Постачання** (`workspaces.kind = 'fcl'`). Усе, що вміє поставка, працює і в збірнику й надалі не розходиться. Таблиця `collections` мігрує в `workspaces` з тим самим id |
| Партія | **Один постачальник = одна партія.** У партії може бути кілька позицій (у контейнері 10 позицій, 4 з них від одного постачальника) |
| Розкладання по партіях | **Авто + ручна правка.** Після читання файл сам потрапляє в партію за продавцем / товаром / HBL; невпевнені — в Інбокс із підказкою; користувач переносить вручну |
| Папки | Спільні папки FCL (Маніфест, Транспорт, Митниця, Інбокс) **+ папка на кожну партію** «Партія — <постачальник>». Перенесення файлу між папками = зміна партії |
| Отримувач | За замовчуванням **наша компанія** на рівні FCL; партія може мати **свого** отримувача |
| Контекст | Рівень FCL: транспорт, маршрут, режим, країна призначення, транзит через ЄС. Рівень партії: Incoterms, категорія товару, тип контракту, сторони (Хто / Через кого / Кому) — з її документів, з можливістю перевизначити |
| Маніфест | **Еталон + звірка.** Кожен рядок маніфесту звіряється з інвойсами/PL партій. Якщо маніфесту немає — він збирається з інвойсів |
| Зведені перевірки FCL | Транспорт цілком · Маніфест ↔ документи · Отримувачі та МД · Регуляторика по всіх позиціях |
| Комплектність FCL | MBL (або MAWB/CMR за видом транспорту) · HBL на кожну партію · T1/NCTS + CMR (коли є транзит через ЄС) · Маніфест · МД на кожного отримувача (для «Готово до митниці») |
| Статус FCL | **За найгіршою партією**: «Документи повні» лише коли повні всі партії і документи FCL. «Готово» ставить людина |
| UI | Вкладки **Файли · Партії · Комплектність · Аналіз · Журнал**. «Партії» — таблиця зі світлофором + «Без партії: N файлів». «Комплектність» — як у поставки, з перемикачем «Весь FCL / Партія N» |
| Дії | Інструкція **по партіях** · Звіт керівництву FCL (PDF) · ZIP по партіях · XLSX аналізу + аркуші звірки |
| Штурман | **Усі інструменти поставки** з параметром «партія» + аналіз маніфесту + нові: список партій, перенести файл у партію, зведена перевірка FCL |
| Наявні збірники | **Мігрувати й перечитати** файли; історія чатів та архів аналізів зберігаються |
| Здача | Тікети комітами в `main`, typecheck/test/build на кожен; push — після підтвердження замовника; приймання на «Сборник 18 Китай» |

## Модель

```
workspaces (kind = 'fcl')          ← FCL: контекст рівня FCL, статус = найгірша партія
 ├─ folders: 01_Маніфест, 02_Транспорт, 03_Митниця      (lot_id NULL — рівень FCL)
 ├─ folders: «Партія — Shandong X» (lot_id = L1) …     (одна на партію)
 ├─ lots: L1, L2, …                 ← постачальник, контекст партії, статус партії
 ├─ files → folder → lot            ← партія файлу = lot_id його папки (одне джерело)
 ├─ parties (lot_id NULL | L1 …)    ← сторони FCL / партії
 ├─ workspace_checklist_items (lot_id NULL | L1 …)
 └─ analyses (workspace_id)         ← аналіз маніфесту
```

- Партія файлу визначається **лише** папкою (`folders.lot_id`). Файл в Інбоксі
  чи в папці FCL — без партії.
- Вердикти партії — той самий `computeVerdicts` над файлами партії з контекстом
  партії (`ws` з перевизначеними `incoterm_*`, `product_category`, `contract_type`).
- Вердикти рівня FCL — новий чистий модуль `reconciliation/fcl.ts`: комплектність
  FCL, транспорт цілком, отримувачі/МД, маніфест ↔ документи, зведені ризики.
- Будь-який запис у те, що читають вердикти (зокрема перенесення файлу між
  партіями, зміна контексту партії) закінчується `shipmentChanged(id, change)`;
  для FCL він перераховує всі партії та рівень FCL.

## Автоматичне розкладання по партіях (детерміновано)

Після витягу полів (`worker` → `classifyAndFile`) для FCL:

1. `transport` з видом MBL / T1 / CMR / маніфест → папки FCL. `customs_declaration` → Митниця.
2. HBL → партія, чий постачальник = shipper / consignor HBL.
3. `invoice` / `packing_list` / `contract` → партія за **продавцем**. Якщо продавець —
   посередник рівня FCL (або в ланцюгу перепродажу), партія — за збігом товарів
   (позиції рядків) з наявною партією.
4. `certificate_of_origin` / `quality_certificate` / інше → партія за виробником,
   експортером, назвою товару або номером партії товару.
5. Новий продавець з якірного документа (invoice / contract / PL) → **нова партія**
   (`source = 'auto'`). Сертифікати й інші документи нові партії не створюють.
6. Неоднозначно → файл лишається в Інбоксі з підказкою «ймовірно: Партія X».

Користувач переносить файл у папку іншої партії → партія змінюється → перерахунок.

## Нові поля витягу

`transport_doc_kind` (`mbl | hbl | awb | cmr | transit | manifest | other`),
`container_numbers[]`, `vessel`. Опційні; старі витяги їх не мають до перечитування
(мігровані збірники перечитуються).

## Зведені перевірки FCL (`reconciliation/fcl.ts`, чисті функції)

1. **Транспорт цілком**: номер контейнера однаковий у MBL / HBL / T1 / CMR; сума ваги
   брутто і місць по HBL = MBL (допуск 1%); T1 = MBL; брутто PL партії = її HBL.
2. **Маніфест ↔ документи**: кожен рядок маніфесту знаходить позицію інвойсу
   (нечіткий збіг назви); кількість (кг) і ціна збігаються; рядки без інвойсу та
   товари інвойсів поза маніфестом — 🟡.
3. **Отримувачі та МД**: перелік отримувачів (FCL + перевизначення партій); кожен має
   ≥1 партію; МД на кожного — вимога для «Готово до митниці».
4. **Регуляторика**: ризики всіх партій + реєстр ліків + перевірки аналізу маніфесту
   (EU/UA, прекурсори, подвійне призначення) → світлофор FCL.

Ранжування як у поставки: 🔴 підтверджено двома цитатами, 🟡 — підозра.
