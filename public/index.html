AI Import Assistant — Backend

Це бекенд (Fastify + один агент «Штурман»). Він працює на власному сервері через Docker Compose, а не на Vercel — бекенду потрібні окремий воркер індексації, постійний диск, тривалі SSE-стріми та Postgres / Qdrant / Redis.

Ця сторінка — лише плейсхолдер, щоб збірка Vercel проходила й перевіряла компіляцію TypeScript. Реальний API тут не обслуговується.

Розгортання бекенду: docker compose up -d --build — див. DEPLOYMENT.md. Контракт для фронтенду: API_CONTRACT.md. Фронтенд (Vercel) вказує на бекенд через NEXT_PUBLIC_API_URL.
